Helicopter Delivery System

Командный проект по дисциплине «Технологии программирования для мобильных приложений»: консольное приложение на C/C++ с SQLite, управлением версиями, CI и документацией.

Предметная область — вариант 3: «Воздушный извозчик» (учет вертолетов, экипажей, рейсов, начислений и ограничение по летному ресурсу после капремонта).
