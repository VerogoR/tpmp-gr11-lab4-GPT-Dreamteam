# Глоссарий

Термины, используемые в проекте «Воздушный извозчик».

| Термин | Пояснение |
|--------|-----------|
| **Вертолёт** | Единица техники авиаотряда: номер, марка, дата изготовления, грузоподъёмность, дата последнего капитального ремонта, **летный ресурс** (лимит часов после капремонта). |
| **Экипаж** | Три постоянно закреплённых за вертолётом специалиста: табельный номер, ФИО, должность, стаж, адрес, год/дата рождения, привязка к номеру вертолёта. |
| **Рейс** | Факт перевозки: дата, код рейса, вертолёт, масса груза, число перевезённых людей, длительность полёта, стоимость, признак **спецрейса** или обычного. |
| **Командир авиаотряда** | Роль в приложении: полный доступ к аналитике по отряду, CRUD справочников, начислениям всем экипажам, управлению пользователями. В БД пользователь командира не привязан к строке экипажа (`AIR_CREW_number IS NULL`). |
| **Лётчик / член экипажа** | Роль с ограниченным доступом: «свои» рейсы и расчёты начислений по своему табельному номеру; командир при необходимости смотрит рейсы по выбранному вертолёту. |
| **Летный ресурс** | Максимальная суммарная длительность рейсов (в тех же единицах, что `flight_duration`) после даты последнего капремонта; превышение блокируется триггером при вставке рейса. |
| **Начисление (процент)** | Доля от стоимости рейса, положенная экипажу: для обычного рейса и спецрейса хранится в `AIR_CONFIG` (например 5% и 10%). |
| **Таблица начислений за период** | `AIR_PAYROLL_PERIOD`: результат расчёта выплат по каждому члену экипажа за выбранные даты. |
| **BLOB / изображение** | Дополнительный формат хранения: таблица `AIR_IMAGES` связывает двоичные данные (например фото вертолёта) с записью в основной таблице. |
