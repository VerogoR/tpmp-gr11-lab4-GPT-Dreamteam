Спецификация проекта «Приемная комиссия»

Условие

Упражнение 2.3
«Абитуриент»: id; фамилия; имя; отчество; пол; национальность; дата рождения
(год, месяц, число); домашний адрес (индекс, страна, область, район,
город, улица, дом, квартира); оценки по ЦТ; проходной балл.

Упражнение 2.4
Выполнить запросы:
- вывести абитуриентов с проходным баллом >= 225;
- через ALTER добавить столбцы, один из них vuz_id;
- создать таблицу vuz (id, vuz_name, vuz_description);
- вывести данные об абитуриентах с названием вуза;
- count для проходного балла > 250;
- sum баллов при пол=муж;
- max/min балла;
- inner join по вузу с id=3.
