Дополнительная спецификация

Надежность и целостность данных

  • Включены внешние ключи SQLite: PRAGMA foreign_keys = ON.
  • Ограничение летного ресурса реализовано триггером до вставки в AIR_FLIGHTS.
  • Инициализация схемы идемпотентна: базовые таблицы и расширения создаются с IF NOT EXISTS.

Безопасность

  • В учебной БД пароли хранятся в открытом виде (для production требуется хэширование).
  • Разграничение доступа реализовано на уровне приложения (командир/экипаж).

Удобство использования

  • Консольное меню с нумерованными пунктами на русском языке.
  • Подсказка по демо-входу при HELI_SEED=1.
  • Поддержка флага --help и переменных HELI_SQL_DIR, HELI_SEED.

Производительность

Для учебного объема данных индексов по первичным ключам достаточно. При росте объема рекомендуется добавить индексы по AIR_FLIGHTS(date) и AIR_FLIGHTS(AIR_HELICOPTERS_number).

Сопровождаемость

  • Разделение по модулям: auth, queries, mutations, payroll, storage, db.
  • SQL вынесен в файлы и может быть повторно применен при пустой БД.

Функциональные ограничения

  • Один файл SQLite на запуск (по умолчанию build/helicopter.db).
  • Формат дат: YYYY-MM-DD.
