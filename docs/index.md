# 🚁 Helicopter Delivery System

## Кратко о задаче

Командный проект по дисциплине **«Технологии программирования для мобильных приложений»**: консольное приложение на **C/C++** с SQLite, управлением версиями, CI и документацией. Предметная область — **вариант 3: «Воздушный извозчик»** (учёт вертолётов, экипажей, рейсов, начислений, ограничение по летному ресурсу после капремонта).
